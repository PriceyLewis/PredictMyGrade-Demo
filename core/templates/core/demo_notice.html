Demo Notice

Last updated: {% now "j F Y" %}

PredictMyGrade is a portfolio/demo build for showing product design and engineering work. It is not a live student service, commercial SaaS product, or compliance-ready platform.

What Is Mocked

  • Billing and subscription flows are simulated locally. No card details are requested and no real payment processor is used.
  • Premium can be enabled, switched between illustrative monthly/yearly plans, and returned to Free so reviewers can verify feature gating.
  • Assistant replies are deterministic demo responses while mock billing is enabled; they do not call an external AI service.
  • Third-party sign-in is intentionally hidden from the demo login experience.
  • Cookie, privacy, and legal-style pages are portfolio content, not audited production controls.

What Is Real In The Repo

  • The app uses real Django routing, templates, local authentication, and database persistence for testing and demonstration.
  • Module changes, settings, exports, imports, backups, predictions, and plan state persist in the configured demo database.
  • Premium feature gates use the same application state that the mock checkout changes, so the Free/Premium walkthrough exercises real app logic without real billing.

How To Review Safely

  • Use the "Continue as Demo User" button and throwaway/sample data only.
  • Use the mock Upgrade and Manage Plan screens to test Premium and Free states.
  • Do not treat this repository as a launched service or enter real payment, identity, or sensitive student information.
  • Production integrations, policies, security review, monitoring, support processes, and compliance work would need to be designed separately before any real launch.
