# PredictMyGrade Demo — v1.0.0 Portfolio Release

**Release date:** 20 September 2026  
**Status:** Recruiter-ready portfolio release

Recruiter-ready Django product demo with verified Free/Premium journeys, forecasting tools, persistence and browser automation.

## Release highlights

- Disposable demo sign-in with seeded academic data
- Module CRUD, forecasting, goals, deadlines, snapshots and calendar exports
- What-if simulations and AI-style deterministic demo experiences
- Mock subscription upgrade, plan management and downgrade flows
- Responsive UI and persisted settings/theme behaviour

## Verification completed

- Django configuration, migrations and backend regression tests pass.
- Playwright E2E coverage passes across desktop and mobile, dark and light modes.
- Free → Premium → Free mock billing journeys are verified.
- Live Render smoke testing passes.
- Mobile cookie-consent UI is regression-tested so it does not cover the upgrade CTA.

## Portfolio scope

This release is intentionally presented as a portfolio/demo build. It demonstrates implemented engineering work and verified user journeys without claiming production deployment, certification, commercial readiness or operational guarantees beyond the documented scope.
